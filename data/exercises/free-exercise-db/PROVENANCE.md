# منبع داده کتابخانه حرکات — سند مآخز و مجوز (مرحله ۱۸)

## ۱. منبع اصلی import — Free Exercise DB

| مورد | مقدار |
| --- | --- |
| نام منبع | Free Exercise DB (`yuhonas/free-exercise-db`) |
| نشانی | https://github.com/yuhonas/free-exercise-db |
| نسخه مصرف‌شده | شاخه `main`، فایل `dist/exercises.json` — دریافت ۲۰۲۶-۱۰-۲۰ |
| تعداد رکورد منبع | ۸۷۶ |
| مجوز | **Unlicense** (مالکیت عمومی) — https://unlicense.org |
| متن مجوز | `data/exercises/free-exercise-db/LICENSE.md` (نسخه کامل همراه مخزن) |

### شرایط استفاده

مجوز Unlicense یعنی «نرم‌افزار آزاد و بی‌قید منتشرشده در مالکیت عمومی»؛ استفاده
تجاری، بازنشر، ویرایش و ادغام در محصول **بدون هیچ شرطی** مجاز است (نه اجباری
نسبت‌دهی، نه اشتراک مثل، نه محدودیت میدانی). این داده‌ها پایه هیچ ادعای
پزشکی نیستند و در محصول به‌عنوان «آموزش عمومی» ارائه می‌شوند.

### فرایند ثبت مآخز

- فایل خام `exercises.json` عیناً در `data/exercises/free-exercise-db/` نگهداری
  می‌شود تا هر زمان امکان راستی‌آزمایی رکوردبه‌رکورد وجود داشته باشد.
- هر رکورد وارد‌شده در جدول `Exercise` با `sourceKey = "free-exercise-db"` و
  `sourceRef = <شناسه اصلی منبع>` ذخیره می‌شود؛ نسخه مجموعه‌داده و تاریخ import
  در `ExerciseImportBatch` ثبت می‌گردد.
- محتوای آموزشی این رکوردها (خلاصه و مراحل) ترجمه مستقیم متن انگلیسی منبع است
  و «زبان محتوا» آن‌ها صادقانه `en` ثبت شده است؛ فیلدهایی که منبع برایشان داده
  ندارد (تنفس، اشتباهات رایج، نکات ایمنی) **عمداً خالی** مانده‌اند و هیچ مقدار
  ساختگی‌ای برایشان ساخته نشده است.

### نگاشت واژگان (سندشده در اسکریپت import)

- `level`: beginner → مبتدی، intermediate → متوسط، expert → پیشرفته
- `equipment`: نگاشت به واژگان بانک (شامل افزودن کتل‌بل، توپ پزشکی، توپ سوئیسی،
  فوم‌رولر، هالتر خم و «سایر تجهیزات» به واژگان تجهیزات)
- `primaryMuscles`/`secondaryMuscles`: نگاشت به گروه‌های عضلانی بانک؛ سه گروه
  «داخل ران»، «کمر (راست‌کننده‌های ستون)» و «گردن» به واژگان کتابخانه افزوده
  شدند (در مربی سه‌بعدی این سه گروه Mesh اختصاصی ندارند و در هایلایت سه‌بعدی
  ظاهر نمی‌شوند — صادقانه).
- `category` منبع → «نوع تمرین» (قدرتی، کششی، پلایومتریک، پاورلیفتینگ،
  وزنه‌برداری المپیک، استرونگمن، هوازی) — عیناً از داده منبع، بدون ساختگی.
- الگوی حرکتی: قواعد کلیدواژه‌ای + فیلد `force` منبع؛ موارد نگاشت‌نشده با
  برچسب صادقانه «سایر» ثبت می‌شوند و در گزارش import شمرده می‌شوند.

## ۲. رکوردهای ویرایشی پروژه (۴۸ حرکت)

- ۴۸ حرکت موجود بانک، محتوای ویرایشی دوزبانه کامل خود را حفظ می‌کنند؛
  `sourceKey = "editorial"` و `sourceLicense = "proprietary-original"`.
- شناسه‌های پایدار این ۴۸ رکورد عیناً حفظ شده‌اند (ارتباط برنامه‌ها، جلسات و
  مربی سه‌بعدی دست‌نخورده می‌ماند).
- فایل‌های TS این بخش (`src/lib/exercises/data-*.ts`) به‌عنوان «منبع ویرایش»
  باقی می‌مانند و import اسکریپتی آن‌ها را در DB همگام می‌سازد (idempotent).

## ۳. گزینه‌های رسیدن به ~۱۵۰۰ حرکت (بررسی صورت‌گرفته)

| گزینه | وضعیت مجوز | جمع‌بندی |
| --- | --- | --- |
| Free Exercise DB (مصرف‌شده) | Unlicense — بدون قید | تنها منبع آزاد باکیفیت؛ ~۸۷۶ حرکت |
| RepDB | تجاری (۴۹۹$ استاندارد؛ tier رایگان با نسبت‌دهی اجباری) | ~۶۵۰ حرکت + ۵۲۴ انیمیشن؛ برای پوشش کامل سه‌بعدی مرحله ۱۹ گزینه خرید است |
| wger | AGPL-3 برای کد؛ داده تمرین CC-BY-SA (به‌ازای هر رکورد) | ~۲۰۰+ حرکت چندزبانه؛ مصرف داده نیازمند رعایت Attribution-ShareAlike برای همان داده‌هاست — در صورت نیاز آینده با نگهداری مجوز جداگانه امکان‌پذیر است |
| Kaggle «1500+ exercises» / ExerciseDB API | مجوز بازنشر مشخص/تضمین‌شده ندارد | **رد شد** — ریسک حقوقی بازنشر در محصول |

**نتیجه صادقانه**: با منابع دارای مجوز آزادِ قابل‌استناد، مجموعه معتبرِ
قابل‌دستیابی در این مرحله ~۹۰۰ حرکت یکتاست (۴۸ ویرایشی + ~۸۷۶ منبع آزاد پس از
اعتبارسنجی). رسیدن به ۱۵۰۰ نیازمند ترکیب wger (با رعایت CC-BY-SA) یا خرید
مجوز تجاری (RepDB) است؛ افزودن داده ساختگی برای پر کردن فاصله ممنوع و انجام
نشده است.
